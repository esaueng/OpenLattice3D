# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/esaueng/OpenLattice3D/security/advisories/new).
Do not post vulnerabilities, credentials, or confidential files in public issues.

Include the affected version or commit, reproduction steps using a minimal
non-sensitive example, expected and actual behavior, and the potential impact.
Redact tokens, personal information, and private project data from attachments.

## Supported versions

Security fixes target the current default branch. Older versions do not have a
separate security maintenance commitment.
